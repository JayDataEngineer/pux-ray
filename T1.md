# T1 — WDC Parity: Full LTX2 Director Feature Set

17 items the original WhatDreamsCost workflow has that our editor doesn't.

## 🔴 CRITICAL — Core generation capabilities

### 1. Distilled mode is a separate pipeline, not a toggle
- `ltx2_pipeline: "distilled"` loads a different pipeline class (8 steps, no CFG, NAG support)
- Model choice happens at LOAD time, not generation time
- **Need**: Register distilled model variants as separate model entries in VIDEO_MODELS
- Backend: may need separate service registry entries (ltx2_22B_distilled, ltx2_19B_distilled)
- Distilled supports: control video, pose/depth/canny transfer, outpainting, HDR, frame injection
- Dev supports: APG, CFG Star, perturbation, alt guidance, res2s sampler

### 2. Sliding window for long videos
- Params: `sliding_window_size` (default 481), `sliding_window_overlap` (default 9)
- Lets you generate videos > native context window by chunking with overlap
- Essential for anything > ~5 seconds at 24fps
- **Need**: Inspector controls for window size + overlap, checkbox to enable

### 3. Self-Refiner — automatic quality improvement
- After initial generation, re-runs denoising on uncertain regions
- Params: `self_refiner_setting` (on/off), `self_refiner_plan` (e.g. "2-8:3"), `self_refiner_f_uncertainty`, `self_refiner_certain_percentage`
- 466 lines of sophisticated logic in self_refiner.py
- **Need**: Inspector section with enable toggle + plan string + uncertainty slider

### 4. Control Video / IC-LoRA — pose, depth, canny, raw video transfer
- `video_prompt_type` selects mode: PVG (pose), OVG (pose+align), DVG (depth), EVG (canny), VG (raw)
- `video_guide` = the control video file
- `denoising_strength` = how closely to match control (higher = closer)
- Uses `union_control_lora` baked in
- **Need**: Video upload for control video, mode dropdown, strength slider. Distilled only.

### 5. HDR conversion (22B distilled only)
- `video_prompt_type: "V&G"` activates HDR IC-LoRA
- Uses `ltx-2.3-22b-ic-lora-hdr-0.9.safetensors` + scene embeddings
- **Need**: Mode in control video section, only shows for 22B distilled

### 6. Spatial outpainting (22B distilled only)
- `video_guide_outpainting` + `video_guide_outpainting_ratio`
- Uses `ltx-2.3-22b-ic-lora-outpaint.safetensors`
- Extends canvas beyond original dimensions
- **Need**: Outpaint toggle + ratio, only shows for 22B distilled with control video

## 🟡 IMPORTANT — Generation quality parameters

### 7. Advanced guidance modes
- **APG** (Adaptive Projected Guidance): `apg_switch` (0/1) — dev only
- **CFG Star** (rescaling): `cfg_star_switch` (0/1) — dev only
- **NAG** (Negative Attention Guidance): `NAG_scale`, `NAG_tau`, `NAG_alpha` — distilled only
- **Alt Guidance** (Modality Guidance): `alt_guide_scale`, `alt_scale` — dev only
- **Need**: Inspector section "Guidance" with mode-specific controls

### 8. Sample solver selection
- 22B dev: `"euler"` or `"res2s"` (higher quality, slower)
- 19B dev: `"euler"` only
- Distilled: locked to 8 steps
- Preset "HQ (Res2s)" uses res2s with 15 steps
- **Need**: Dropdown in Generation section, only for dev models

### 9. Perturbation control
- `perturbation_layers`: which transformer layers (default [28] for 22B, [29] for 19B)
- `perturbation_start` / `perturbation_end`: % of denoising to apply (0.0-1.0)
- We have on/off/skip-attn, but not fine-grained layer/range control
- **Need**: Layer input + start/end sliders, only when perturbation enabled

### 10. Mask injection
- `masking_strength`: 0.0-1.0, controls region-specific denoising
- `masking_source`: "", "A", "NA", "XA", "XNA" — mask preprocessing modes
- `input_masks`: mask images
- **Need**: Mask strength slider + preprocessing dropdown + mask image upload

## 🟢 MODERATE — Workflow/pipeline features

### 11. Keyframe interpolation pipeline
- Separate pipeline (keyframe_interpolation.py)
- Takes `images: list[tuple[image, frame_position, strength]]`
- Interpolates between placed keyframes spatially
- Different from prompt relay (temporal) and FFLF (start/end only)
- **Need**: Per-segment keyframe list with image + position + strength

### 12. Preset profiles
- JSON files in `opt/wan2gp/profiles/ltx2_presets/` and `ltx2_distilled_presets/`
- Pre-tuned parameter sets for quality/speed tradeoffs
- "HQ (Res2s)", "Standard Dev (Euler)", "VBVR LoRA"
- **Need**: Gateway endpoint to list presets, dropdown in editor that applies preset

### 13. Prompt enhancement (built-in LTX2)
- `prompt_enhancer.py` rewrites prompts with [VISUAL]/[SPEECH]/[SOUNDS] tags
- Context-aware: different instructions for I2V, audio-driven, ID-LoRA, etc.
- Already in wan2gp, just needs `enhance_prompt: true` flag
- **Need**: "Enhance Prompt" button per segment that passes the flag

### 14. Frame injection
- `frames_to_inject`: inject specific latent frames at positions during generation
- `frames_relative_positions_list`: frame position data
- `custom_frames_injection: true` in handler
- **Need**: UI for placing reference frames at specific positions within a segment

### 15. Audio conditioning modes
- `""` — Text only (generate video + optional soundtrack)
- `"A"` — Audio-driven (feed soundtrack, generate video matching it)
- `"A1OF"` — Reference Voice with ID-LoRA (dev only)
- `"K"` — Control video audio track (distilled only)
- `"2"` — Generate audio FROM control video (distilled only)
- Currently hardcoded to "A" when audio cues exist
- **Need**: Dropdown in audio section, mode descriptions

### 16. ID-LoRA (identity preservation)
- `id-lora-celebvhq-ltx2.3.safetensors` + `id-lora-celebvhq-ltx2.safetensors`
- When selected + `audio_prompt_type: "A1OF"` = consistent character faces
- Currently shows in LoRA picker but doesn't enable the mode
- **Need**: When ID-LoRA selected, auto-suggest A1OF mode, show character identity section

### 17. Input video strength / source strength
- `input_video_strength`: controls how strongly first frame conditions output
- Lower values = more motion freedom from the start image
- SEPARATE from `denoising_strength` (which is for control video)
- **Need**: Slider "Start Image Strength" in Frames section, default 1.0
